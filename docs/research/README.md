# Hook study: big Minecraft Shorts (owner fetches, lead analyses)

`hook_study.csv`: 114 Shorts from 16 Minecraft channels, each channel's 6 most-viewed plus its 2 least-viewed (the
contrast pair), with views from `yt-dlp --flat-playlist` on 2026-11-11. `hook_study_urls.txt` is the same list, one URL per
line, for yt-dlp. The videos themselves are other creators' work: research only, never committed (media policy).
